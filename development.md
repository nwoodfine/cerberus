# Development Guide

## Local Development

1. Make sure you have Ruby 3.2.2 installed
2. Install dependencies: `bundle install`
3. Run the site locally: `bundle exec jekyll serve`
4. View the site at: http://localhost:4000/cerberus/

## Theme Customization

This site uses a custom fork of Just the Docs located at:
https://github.com/nwoodfine/style-the-docs

To make theme changes:
1. Clone the theme repository
2. Make changes to the theme
3. Push changes to the theme repository
4. The site will automatically use the updated theme
